## 2026-10-28 恢复处理规程统一

所有技能入口、工作器规程、自动化提示和智能体适配说明统一采用以下规则：用户明确要求继续/恢复即为一次恢复授权；恢复前只做一次页面检查；检查失败不清除暂停、不重发、不重复追问；只有新的明确继续指令才允许再次检查。该规则不改变未知提交、验证码、额度或登录故障必须暂停的要求。

浏览器集成断开时由当前获准集成自动重连一次；租约恢复依据 `status --verbose` 的 `run_id` 和 `expires` 判断，过期租约自动回收，不能证明归属的有效租约不抢占，不要求用户手动声明租约失效。

### 网页操作实测要点

- **旧发送结论已被后续实测推翻**：2026-11-05 在 WorkBuddy 指定外部 Chrome 的真实用户标签中，`dom_cua_click` 语义节点点击发送成功；不应再把 CDP 超时或坐标点击失败归因于 Gemini 按钮本身。
- 输入框可能未自动聚焦；若低层 DOM 输入调用返回但文本未落地，应在同一内置浏览器中用坐标建立焦点、键盘输入，再回读 DOM 确认文本和发送节点，随后用语义节点点击发送。
- **Notebook 空白入口可用**：2026-11-05 实测从登记 Notebook 的空白入口提交会跳转到 `/app/<id>` 并生成回复，chat URL 可捕获。此前“从笔记本首页不跳转、不生成，需要普通 `/app/` 入口并事后 Add to notebook”的观察已失效，不得继续作为当前流程规则。
- `Rename` 表单同时存在两个 `input[aria-label="Rename this chat"]`（旧的与新的），必须填最后一个，否则新名会追加到旧名后面。
- Gemini 单条视频生成实测 10~25 分钟；`Connecting to YouTube` 阶段不算失败，需继续等待。
- 主题词取回复末行的「主题词：X」；模型漏写时从原标题（去除 `｜` 后缀与「王局拍案/新闻特写/新闻大写」等栏目词）取前 1~5 汉字兜底。
